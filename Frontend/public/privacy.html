2. 我們預計處理的資料

  • 帳號資料：電子郵件、選填名稱、密碼雜湊、郵箱驗證狀態、時區、帳號角色及建立／更新時間。
  • 學習與偏好：已學內容、作答與複習次數、熟練度、到期時間、反應時間、每日完成量、連續學習紀錄、每日目標、聲音、提醒、觸覺及自動前進設定。
  • Notes：使用者輸入的英文、翻譯、分類及其與學習內容的關聯。
  • 安全與工作階段：雜湊後的 refresh token、工作階段時間、IP 位址、瀏覽器或裝置 user agent，以及郵箱驗證／密碼重設權杖的雜湊與時間。
  • 診斷資料：請求 ID、路由、HTTP 狀態、處理時間，以及啟用錯誤追蹤後的錯誤、環境與版本資訊。現有設定要求錯誤追蹤不主動傳送預設個人識別資料。

密碼本身不以明文保存。ChunkMaster V1 不計畫要求定位、聯絡人、相機或麥克風權限，也尚未加入廣告或產品分析 SDK。

3. 預計用途

  • 建立、驗證及保護帳號，提供登入、登出與密碼重設。
  • 同步學習進度、SRS 複習、每日目標、偏好及 Notes。
  • 提供資料匯出、帳號刪除及使用者支援。
  • 偵測錯誤、維護服務安全與可靠性，並防止濫用。

4. 第三方處理者與資料傳輸

發布計畫預計評估下列供應商；在完成合約、地區、子處理者及保存設定前，不應把此清單視為已啟用的 production 清單：

  • Neon：PostgreSQL 資料庫與備份。
  • Railway：後端 API 與執行日誌託管。
  • Cloudflare Pages：網頁託管與邊緣傳輸。
  • Resend：帳號驗證與密碼重設郵件。
  • Sentry：網頁、Android 與後端錯誤診斷（僅在設定 DSN 後啟用）。
  • OpenAI：管理員發起的學習內容生成。使用者的私人 Notes 不會送入此流程。

5. 保存、匯出與刪除

登入後可在設定中匯出帳號資料。現有 App 內刪除流程要求再次輸入密碼；成功後會刪除主要帳號資料，並以資料庫關聯級聯刪除偏好、學習進度、Notes、工作階段及驗證／重設權杖。

管理稽核事件在刪除帳號後可能保留但解除與帳號的直接關聯；事件快照是否可能含個人資料仍須審核。備份及供應商日誌中的副本不一定會同時即時消失。

6. 安全與使用者權利

系統預計使用 TLS、存取控制、密碼雜湊、短效 access token 與雜湊 refresh token 等措施。任何系統都無法保證絕對安全。

可適用的查閱、更正、刪除、限制、反對或申訴權利取決於尚未確認的營運司法地區。正式聯絡管道確認前，本草稿無法提供可操作的隱私請求地址。

7. 政策變更

正式政策將標示生效日及重大變更的通知方式。本草稿不構成已生效政策。
